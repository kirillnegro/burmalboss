# ORBIT · Exploration Club

Многостраничный интерактивный космос на HTML, CSS, JavaScript и Three.js. Без сервера приложений, аккаунтов и сборки.

## Запуск

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Используйте HTTP-сервер: ES-модули не загружаются при открытии через `file://`. Все ссылки относительные, сайт подходит для размещения в подпапке GitHub Pages.

### Управление

- **3D:** мышь/касание — вращение или обзор; колесо и +/− — масштаб; стрелки — вращение с клавиатуры. Сначала сфокусируйте окно модели.
- **Свободный полёт:** включите переключатель, затем W/A/S/D — движение, R/F — высота. На телефоне используйте шесть экранных кнопок.
- **Посадка:** нажмите «Начать полёт», затем пробел/↑ — тяга, ←/→ — манёвры, P — пауза. На телефоне удерживайте экранные кнопки. Садитесь в центр площадки при вертикальной скорости ≤ 6 м/с и горизонтальной ≤ 4 м/с. Фоновые вкладки и потеря фокуса приостанавливают полёт.
- **Погружение:** в новых визуальных сценах кнопка разворачивает сцену; Escape или «Выйти» возвращает страницу. Если Fullscreen API недоступен, используется разворот внутри окна.
- **Звук:** синтезируемая атмосфера Web Audio включается только по кнопке, отключается при уходе со вкладки. В 3D-сценах есть регулятор громкости. Звук не требуется для игры или квеста.

## Сохранение и доступность

Паспорт хранится в `localStorage` под ключом `orbit.passport.v1` на текущем origin, без отправки данных на сервер. Очистка данных сайта удаляет прогресс. Между устройствами он не синхронизируется. Экспорт JSON предназначен для сохранения копии; импорта нет. При недоступности хранилища показывается предупреждение, интерфейс продолжает работать в памяти текущей страницы.

Поддерживаются клавиатура, сенсорные кнопки, подписи элементов, текстовые результаты и `prefers-reduced-motion`: автоматическое вращение в новых сценах стартует на паузе. Игра начинается только по явному действию. При отсутствии WebGL отображается понятное сообщение, а текстовые функции сохраняются.

## Технологии и ограничения

- Three.js **0.170.0** хранится локально в `vendor/`; MIT-лицензия — `vendor/THREE-LICENSE.txt`.
- Manrope загружается из Google Fonts; при отсутствии сети используется Arial. Для остальных ресурсов внешняя сеть не нужна.
- Модели и экспедиции художественные. Размеры планет увеличены для видимости. Режим относительных орбит сохраняет пропорции больших полуосей, но не размеры тел; орбиты представлены окружностями.
- Чёрная дыра использует художественную имитацию линзирования, а не расчёт общей теории относительности.
- Посадка использует аркадную модель с марсианской гравитацией. Корпуса меняют вид, но не сложность игры.
- Секретная станция — игровой элемент, а не защищённая область сайта.

## Проверки

Физика посадки (Node.js 20+):

```sh
node --test tests/lander.test.mjs
```

Браузерные проверки требуют установленного `playwright` и Chromium. При запущенном HTTP-сервере:

```sh
node tests/browser.cjs
node tests/landing-browser.cjs
```

Путь Chromium по умолчанию `/usr/bin/chromium`; можно переопределить `CHROMIUM_PATH`. Базовый URL задаётся `ORBIT_BASE_URL` и должен заканчиваться `/`. Playwright нужен только для проверок, не для самого сайта. Тесты используют отдельный браузерный контекст и не изменяют пользовательский паспорт.

Проверяются все страницы, мобильная ширина 390 px, 3D, сохранение корабля, управление посадкой и аварийный сценарий, полный квест, журнал, экспорт/сброс, звук, погружение, уменьшение движения и отсутствие хранилища/WebGL. Успешную управляемую посадку проверяют тест физики и отдельный браузерный сценарий: он управляет кораблём клавиатурой по видимой телеметрии и проверяет запись достижения в паспорт.
