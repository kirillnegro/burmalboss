# ORBIT

Адаптивный космический сайт на HTML, CSS и JavaScript: анимированные планеты, карточки направлений, модальные окна и генератор позывного. Без сборки и npm-зависимостей.

## Запуск

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Можно также открыть `index.html` напрямую. Шрифт Manrope загружается из Google Fonts; без сети используется Arial. Поддерживается `prefers-reduced-motion`, клавиатурная навигация и закрытие окон клавишей Escape.

Это художественный проект, а не сервис бронирования космических полётов. Введённое имя обрабатывается только в браузере.

## Новые страницы

- `atlas.html` — WebGL-модели Марса, Сатурна с кольцами и Европы. Вращение мышью/касанием или стрелками, масштаб колесом или клавишами +/−, пауза, скорость и каркас.
- `mission.html` — персональная виртуальная экспедиция со скачиванием текстового талона.
- `lab.html` — симулятор орбит и калькулятор местной гравитации.

Для новых страниц нужен HTTP-сервер (команда выше): ES-модули не работают через `file://`. Three.js 0.170.0 хранится локально в `vendor/`, лицензия MIT — `vendor/THREE-LICENSE.txt`. Для 3D требуется WebGL; при недоступности показывается сообщение, а факты остаются доступны. Модели процедурные и художественные. Орбитальные расстояния и размеры не в масштабе. При включённом уменьшении движения симуляции стартуют на паузе.
